Calibrated, Evidence-Grounded Medical Image Decision Support

Two diagnostic modules built on stacking ensembles of CNNs, wrapped in a layer that reports how much to trust each answer and what the answer is based on. This page records the method and the measured results, including the parts that do not work well.

Provenance convention. Every figure below is tagged. measured means measured on this codebase. documented means carried forward from the training runs. not recorded means the value does not exist in the repository and would have to be regenerated. Nothing here is estimated or rounded up.

Calibration

Stacking consumes probabilities, so how well-calibrated they are directly determines the quality of the combiner. Expected Calibration Error was measured and temperature scaling fitted on a 320-image calibration split, evaluated on a disjoint 480-image final test split.

The interesting result is not the ECE, it is the temperatures measured

ComponentFitted temperatureReading
EfficientNet-B03.3542severely over-confident

A temperature above 1 means the output needs softening. The base CNNs need it badly; the meta-learner needs essentially none. The stacking layer is performing calibration as a side effect — which explains why stacking helps here, beyond the accuracy gain.

Output-level ECE therefore improves only marginally, from 0.026201 to 0.025949, with adaptive (equal-mass) ECE going from 0.013439 to 0.013298. Both are reported on purpose: conventional 15-equal-width-bin ECE is inflated here because 454 of 480 samples land in the top bin, so bins holding one to four samples dominate the average. Quoting only the flattering number would be misleading; quoting only the conventional one would overstate the miscalibration.

Conformal prediction: abstention with a guarantee

Rather than picking a confidence threshold by hand, the system uses split conformal prediction. An empirical quantile is fitted on the calibration split, and the model returns the set of classes it cannot statistically exclude. The guarantee is distribution-free and finite-sample: the true class lies in the set with probability at least 1 − α under exchangeability.

Why α = 0.01 and not the textbook 0.10

Conformal sets collapse to singletons whenever 1 − α is below the model's accuracy — coverage then merely equals accuracy and the layer carries zero information. At 97.71% accuracy, any α above 0.0229 is vacuous. A finite-sample floor closes the window from below: with 320 calibration images, α below 0.0031 forces the quantile to 1 and admits every class. The usable window is narrow because the model is good, and both bounds are recorded in the artefact rather than discovered by accident.

Input validation and novelty detection

A softmax always sums to one over the classes it knows, so an unfamiliar image still produces a confident answer. Two independent layers address this, benchmarked on a three-tier evaluation set so that synthetic noise could not flatter the result.

Note also the 0.31 AUROC gap between graded disagreement (JS divergence over the full distributions) and binary disagreement (argmax votes) — the information is in the probability geometry, not in the votes.

The tier a detector is chosen on is a design decision with consequences. On synthetic patterns alone, max-softmax looks best (AUROC 0.978). Selecting there would have shipped the detector that is worst on the realistic case. The choice was made explicitly on the hard tier and recorded in the artefact.

Explainability

Grad-CAM on the agreeing model

Gradient-weighted Class Activation Mapping backpropagates the predicted class through a base model's last convolutional block, globally average-pools the gradients into channel weights, weights the feature maps, then applies ReLU and normalisation. The heatmap is overlaid on the original scan with the JET colormap at 40% opacity.

The subtlety is which model to explain. The ensemble's prediction comes from the meta-learner, which has no convolutional layers. So the system finds the base model whose own top-1 matches the ensemble and explains that one. When no base model agrees, any heatmap necessarily explains a different class than the one reported — so the API returns explanation_faithful: false and the interface says so instead of showing a misleading picture.

Grad-CAM is implemented directly rather than via pytorch-grad-cam. The hand-written path honours the requested target class explicitly; the library's default would explain the base model's own argmax, which is not necessarily the class being reported.

  • Explains the model that agrees with the ensemble
  • Flags unfaithful explanations rather than hiding them
  • Requires no architecture modification
  • Per-architecture target layers for all four CNNs

Evidence grounding

Retrieval over a cited knowledge base

Clinical guidance in the report is retrieved from a knowledge base of 28 chunks drawn from 12 cited sources — NCI and NINDS clinical summaries, StatPearls reference articles, a 2024 Neuro-Oncology consensus review, and the WHO CNS5 classification standard. Every chunk carries at least one citation, enforced at build time.

Retrieval uses all-MiniLM-L6-v2 sentence embeddings. The entire corpus is a (28 × 384) array of about 40 KB, so there is deliberately no vector database: brute-force cosine similarity over a NumPy array is both faster and simpler than any index at this scale. Warm retrieval takes 15.3 ms.

Nineteen of the thirty queries were deliberately paraphrased away from the corpus wording, and that is where the gain concentrates — Hit@3 on paraphrased queries goes from 0.7368 to 0.8947. Complete misses is the metric that matters clinically: a retriever that returns nothing relevant leaves a statement ungrounded. Embeddings cut those by two thirds.

The language model is an offline authoring aid, not a runtime oracle

The output space is finite and small: 4 classes × 3 uncertainty bands = 12 narratives. So a language model was used once, offline, to draft them, with retrieval-augmented prompts and a build-time check that every claim traces to a retrieved chunk. All 12 were grounded on the first attempt, with zero fabricated citations and zero invented statistics.

The application makes no language-model calls at request time. Every narrative sits behind a human-review flag, and the serving path refuses to serve an unreviewed one — it falls back to a deterministic template and reports narrative_source: "template". At present none has been signed off, so the template is what users see. A model that writes clinical text without human approval is not a feature.

Datasets

Brain MRI — training and evaluation

5,600 training images and a 1,600-image test set across four classes, perfectly balanced at 400 per class. That balance matters methodologically: a majority-class baseline scores exactly 25%, and macro-averaged metrics equal micro-averaged accuracy, so every brain figure on this page is directly interpretable. Source images range from 150×168 to 1375×1446 pixels and are resized to 224×224.

Limitations

Stated plainly. A decision-support tool that conceals its failure modes is worse than none at all.

  • No confidence intervals, and no McNemar test. 96.75% on 800 images carries a 95% Wilson interval of roughly ±1.2 points, and the 96.06% → 96.75% ensemble gain sits inside it. The claim that survives scrutiny is the glioma recall gain, 0.81 → 0.90.
  • Conformal coverage of 1.0000 is a point estimate, not a bound. The honest statement is that no coverage violation was observed in 480 trials.
  • The hard novelty tier has only 6 positives. AUROC 0.9538 on six examples is indicative, not established.
  • The novelty detector fires on 7.29% of valid brain MRI. The interface quotes that rate alongside every flag, so a flag reads as a prompt to check the input rather than a verdict that it is invalid.
  • Chest X-ray has no calibration or conformal layer. The fitted artefacts are specific to the brain ensemble's 16 features and 4 classes, so applying them to 3-class chest output would be meaningless. Chest reports calibrated: false and falls back to a confidence threshold. Chest per-model and per-class metrics are not recorded — the training notebooks were saved with outputs cleared.
  • Meta-features come from the test set, not out-of-fold predictions. This deviates from canonical stacking. It was left in place deliberately: correcting it requires refitting the meta-learner, which would invalidate the reproduced 96.75%.
  • Single 2D slice, JPEG or PNG only. Real radiology reads 3D volumes across multiple sequences. There is no DICOM support, so 12-16 bit depth and windowing metadata are lost.
  • No modality auto-detection. A chest X-ray sent to the brain module is classified as a brain tumour. Routing depends on the caller selecting the right module.
  • Single-source datasets. No multi-centre or multi-scanner validation, so scanner-specific artefacts may have been learned as shortcuts. No tumour grading, segmentation or volumetry.
  • No authentication on any endpoint, and CORS is permissive. This is a research prototype and must not be exposed to a network.

Future work

  • Statistical rigour: Wilson intervals on every reported proportion and McNemar's test on paired ensemble-versus-base predictions. This is the most important outstanding item.
  • Out-of-fold stacking: rebuild meta-features from K-fold out-of-sample predictions on the training set, which frees all 1,600 test images for the final estimate and narrows the interval.
  • Calibration for chest X-ray: fit a separate temperature and conformal quantile against the 9-feature, 3-class chest ensemble.
  • Larger novelty evaluation: expand the near-OOD tier well beyond six examples so the AUROC becomes a defensible estimate.
  • DICOM ingestion: read studies via pydicom, honouring window centre and width and preserving full bit depth.
  • Multi-centre external validation: evaluate on data from a different scanner and hospital, which is the only real test of generalisation.
  • Segmentation and volumetry: move from classification to measurement with a U-Net style model, and from a single slice to 3D multi-sequence input.
  • Clinician reader study: AI alone versus clinician alone versus clinician with AI, reporting inter-rater agreement — the accepted way to demonstrate clinical utility.

Intended use

This is a research prototype, not a medical device

NeuraSight has not been validated for clinical use, cleared by any regulator, or tested in a prospective trial. It is a decision-support demonstrator and an academic research artefact.

Outputs are AI-generated and may be wrong, including confidently wrong. Nothing the system produces constitutes a diagnosis or medical advice. Every report carries a non-removable disclaimer, and all findings must be reviewed by a qualified radiologist or specialist physician before any clinical decision.

Clinical content in the knowledge base states well-established fundamentals and cites public sources. It is not reproduced verbatim from those sources and is marked as requiring clinical review.

The design principle throughout is that a system like this earns trust by reporting its own uncertainty and provenance, not by presenting a single number confidently. Where the measurements are weak, this page says so.
